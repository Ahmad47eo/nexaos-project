# Small Linux boot test

Use Alpine Linux Virtual x86_64 as the first ISO test.

Current official release directory:
https://dl-cdn.alpinelinux.org/alpine/latest-stable/releases/x86_64/

The x86_64 Alpine Virtual ISO is a small image intended for virtualized use. Download it from the official Alpine mirror, then select the ISO in NexaOS ISO Lab.

Do not upload the ISO to this repository; keep it local to the browser.
